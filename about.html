Who We Are

Omnori is a relentless product lab building software, automation, and productivity tools of every kind. We prototype rapidly and ship continuously, and release our work as open source under libre licenses so anyone can use it, inspect it, and build on it.

What We Build

  • Nori Cam — A Chrome extension camera app with text and image overlays, basic and advanced filters, zoom, and all the essentials you need for calls and recordings.
  • Pomori — A pomodoro-style clock extension — start and stop custom timers, name them, and stay focused with a few simple, no-nonsense features.
  • Nori Scraptes Images — A Chrome extension that grabs every product image link from a page and lets you copy them in one click. It has dedicated scrapers for Amazon, Flipkart, and Myntra, plus a generic fallback that detects reasonably large images on any other site.
  • Notes 101 — A Discord bot that records on-demand voice meetings, generates notes automatically, and helps teams track updates and progress with regular member check-ins.
  • Link Shortener (coming soon) — Shorten links, manage where each one leads, see who's clicking through, and set a backup redirect for when the destination link expires.
  • Dark Moon — A Computer Software that can control you external display brightness natively , and effortlessly
